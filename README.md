# sysaudit

Quick macOS system security & hygiene audit. Zero dependencies.

## Checks

- 🔥 Firewall status
- 🔒 FileVault encryption
- 🛡️ System Integrity Protection
- 🚪 Gatekeeper
- 🔑 SSH key permissions & remote login
- 📡 Sharing services
- 👤 User accounts
- 🌐 Listening ports

## Usage

```bash
python3 sysaudit.py
```

## Requirements

- Python 3.6+
- macOS
